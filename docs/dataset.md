# Datasets

## Synthetic demo
Generated locally by `make_demo_raw` with a fixed random seed. No download required.

## MNE Sample
Official MNE sample audiovisual dataset, obtained via `mne.datasets.sample.data_path()`.
The app reads `MEG/sample/sample_audvis_filt-0-40_raw.fif` and selects EEG channels.
This recording has already undergone filtering; do not treat it as unprocessed raw EEG.
See https://mne.tools/stable/documentation/datasets.html for licensing and citation details.
